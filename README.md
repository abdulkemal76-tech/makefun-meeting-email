A make.fun bounty entry: a program that writes one original funny line,
at most 200 characters, about a meeting that should have been an email,
to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

## The line

> The birthday committee met two hours to pick Brenda's cake, then sent one email ordering the exact cake Brenda bought herself last year.
